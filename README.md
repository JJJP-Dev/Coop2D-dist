# Coop2D · descargas

Aquí se publican las builds de prueba de **Coop2D** para el grupo de testers. No hace falta descargar nada a mano:
instala **Palito Launcher** y él se encarga de descargar, instalar y actualizar el juego.

**Descargar el launcher:** <https://github.com/JJJP-Dev/PalitoLauncher-dist/releases/latest> → `PalitoLauncher.exe`

Este repositorio lo mantiene una automatización: no contiene el código del juego y no acepta issues ni pull requests.
Para opiniones o problemas usa los botones del launcher (Enviar opinión / Reportar un problema).
